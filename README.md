# D Star — Website & Web App Studio

Clean production source for the D Star website.

## Run locally

```powershell
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```powershell
npm run build
npm start
```

The site is built with Next.js 16, React 19 and TypeScript. It intentionally has no extra UI or animation dependency; the motion system uses browser-native CSS and a small amount of client-side React.
